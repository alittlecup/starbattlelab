## 1. 难度模型

### 1.1 区间制（核心）
- 有一条**全局难度轴**。
- **每条规则 = 轴上的一个难度区间 `[下限, 上限]`**，而不是一个固定值。
- 某一步推理的实际难度 = 落在该规则区间内的一个值：最简单的实例取下限，结构越复杂（数量多、不相连、k 大等）越往上限走。
- **区间允许重叠**——一个简单规则的"困难实例"可以和一个困难规则的"简单实例"难度相当，这是合理的。

### 1.2 区间内难度因子
每条规则内部，难度由若干**结构因子**决定（详见各规则）。通用的因子有：
- **数量**：涉及的格子/集合/k 越多越难。
- **是否相连**：候选格分散（不相连）比紧凑（相连）难。
- **k / n 规模**：鸽笼的 k、鱼的 n 越大越难。

### 1.3 熟练度层（预留，默认关闭）
难度本质上还取决于**玩家对规则/阵型的熟练度**：掌握了的固定阵型会从"高难"降为"一眼认出"。

```
某一步难度 = 结构难度(规则区间 + 因子)  ×  熟练度修正(默认 = 1，不改变难度)
```

- **当前系统默认所有玩家熟练度相同**，所以熟练度层是恒等变换，不影响难度——我们现在只算**客观结构难度**。
- 熟练度（个性化、阵型掌握度）是**预留的未来维度**。

### 1.4 "最便宜路径"原则
> **某一步的难度 = 达成该结论的"最便宜技巧路径"的难度。**

一个结论若既能被某个难技巧一步得到、也能被几个易技巧分步得到，则**按易的算**。（典型：受压排除常可拆成"区域限行 + 普通排除"两小步，引擎会走便宜路径——只有当难技巧能解锁简单序列达不到的格子时，才按难技巧计。）

### 1.5 谜题总难度的聚合（⚠ 待拍板）
候选方案：
- (a) = 全程**最难一步**的难度值；
- (b) = 最难一步 + "用到多少难步 / 难步种类"再加权。
**尚未最终确定**，见 §6。

### 1.6 已确定的全局排序决策
- **反向（已满打叉）< 正向（唯一空格定星）**（选项 B）。
- **行/列 < 区域**：区域版比行列版略难。
- **行 / 列方向解耦，但默认相同**（选项 A）；理由：行列几何对称，"有人擅长横、有人擅长竖"是个人差异、无统一方向，故默认相等，但参数独立、将来可调。
- **邻接打叉**视为"形状固定的区域"，排在"反向行列"之后、"反向区域"之前。
- **唯一性假设是合法推理**（因为所有谜题保证唯一解）——规则 15–17 正当有效，不因用到唯一性而直接判 Expert。
- 鸽笼组合上限 **`MAX_PIGEONHOLE = 7`**（正常棋盘最大 14×14，故 k 最大 7）。

## 3. 逐条规则详解

### 规则 1 · 行/列已满（反向·线）
**含义**：某一行（或一列）已经有了它该有的星 → 该行/列其余格子全部打叉。
**例**：行 0 已在某格放星 → 行 0 其它格打叉。
**区间内因子**：基本恒定（近似定值）。
**关系**：最基础的反向技巧。

### 规则 2 · 邻接打叉
**含义**：任意一颗星的 8 个邻格都不能再有星 → 打叉。
**例**：`(1,1)` 是星 → `(0,0)(0,1)(0,2)(1,0)(1,2)(2,0)(2,1)(2,2)` 全打叉。
**区间内因子**：固定形状（8 邻），近似定值。
**关系**：可看作"形状固定的区域"的反向技巧，故排在反向行列之后、反向区域之前。

### 规则 3 · 区域已满（反向·区域）
**含义**：某区域已经有了它该有的星 → 该区域其余格子打叉。
**区间内因子**：区域格子数量（可能越多略难，待定）。
**关系**：反向技巧中比行/列略难（区域形状不规则）。

### 规则 4 · 行/列唯一空格（正向·线）
**含义**：某一行（或一列）只剩一个空格 → 那个格必是星。
**关系**：正向技巧；按决策 B，正向比反向略难。

### 规则 5 · 区域唯一空格（正向·区域）
**含义**：某区域只剩一个空格 → 那个格必是星。
**关系**：正向技巧中比行/列略难。

---

### 规则 6 · 区域限行/列 ✅因子已定
**含义**：当一个区域所有可能放星的候选格都挤在**同一行**（或同一列）里时，这一行的星就被该区域占用了 → 这一行里**属于其它区域**的格子都打叉。（列方向对偶。）

**例**（看第 0 行）：
```
列:   0 1 2 3 4
行0:  A A B B B
```
- 区域 A 只有 `(0,0)(0,1)`，都在第 0 行 → A 的星必在第 0 行。
- 第 0 行也只能有 1 颗星 → 已被 A 占用。
- 故 `(0,2)(0,3)(0,4)` 打叉。

**区间内因子**（主→次）：
1. **是否相连**（主因子，跳变大）：候选格在那条线上连成一段（相连，易）vs 被打叉的格隔开有空当（不相连，难）。不相连只在已有打叉后出现。
2. **候选格数量**（次因子）：越多越难确认"全部"落在同一线。

**区间内映射示例**（`[30,60]`）：
| 情形 | 难度值 |
|------|--------|
| 相连 + 2 格（最简单） | 30 |
| 相连 + 多格 | 30→45 |
| 不相连 + 2 格 | 45 起 |
| 不相连 + 多格（最难） | 60 |

> 即"是否相连"先把区间劈两半（相连 30–45 / 不相连 45–60），"数量"在各半区内微调。（两半区是否严格不重叠、数量如何归一化，待定。）

---

### 规则 7 · 排除（Exclusion）✅因子已定
**含义**：盯住一个格子 X，如果"在 X 放星"会让**某个区域的全部候选**都变成 X 的邻格而无处安放，则 X 不可能是星 → 打叉。（一步"假设—反驳"推理。）

**例**：
```
列:   0 1 2
行0:  A A B
行1:  A A B
行2:  C C C
```
- 区域 B 只有 `(0,2)(1,2)`。
- `(0,1)` 同时挨着 `(0,2)`（左右）和 `(1,2)`（斜角）→ B 的全部候选都是 `(0,1)` 的邻格。
- 在 `(0,1)` 放星会害死 B → `(0,1)` 打叉。`(1,1)` 同理。

**当前只算一步推理**。固定阵型"掌握后降难"属于熟练度层（默认关闭）。
**区间内因子**：
1. **被威胁区域的候选格数量**：越多越难一眼看出"恰好全是某格的邻格"。
2. **相关格子的分布紧凑度**：越分散越难发现，越紧凑越易。

---

### 规则 8 · 欠计数（Undercounting，区域→线）✅因子已定
**含义**：当 **k 个区域**的候选合起来**恰好只占了 k 条行（或 k 条列）**时，这 k 条线的星全归这些区域 → 这些线上**属于其它区域**的格子打叉。（规则 6 是 k=1 的特例。）

**例**（看区域 A、B；4×4，4 区域）：
```
     c0 c1 c2 c3
r0:  A  A  B  C
r1:  A  A  B  C
r2:  D  D  C  C
r3:  D  D  D  C
```
- A 的格都在行 `{0,1}`，B 的格也都在行 `{0,1}` → 2 个区域占 2 条行。
- 行 0、行 1 的星全归 A、B → 行 0/1 里属于 C 的 `(0,3)(1,3)` 打叉。

**区间内因子**：① **k 值**（越大越难）；② **行/列**方向（解耦默认相同）。
**实现备注**：`MAX_PIGEONHOLE = 7`（k 最大 7）。难度需按 (轴, k) 归因——意味着每一步推理应只对应一个确定的 (轴, k)。

### 规则 9 · 过计数（Overcounting，线→区域）✅因子已定
**含义**：规则 8 的对偶。当 **k 条行（或列）**的候选合起来**只落在 k 个区域**里时，这 k 个区域的星全归这些线 → 这些区域里**不在这 k 条线上**的格子打叉。

**例**（看行 0、行 1）：
```
     c0 c1 c2 c3
r0:  A  A  B  B
r1:  A  A  B  B
r2:  A  C  C  D
r3:  C  C  D  D
```
- 行 0、行 1 的格只属于区域 A、B → 2 条行落在 2 个区域。
- A、B 的星全在行 0/1 → 区域 A 里不在行 0/1 的 `(2,0)` 打叉。

**区间内因子**：同规则 8（k 值 + 行/列）。

---

### 规则 10 · 受压排除（Pressured Exclusion）
**含义**：规则 7 的强化。区域还有一个候选离 X 太远、X 够不着，本来排除不掉；但那个候选其实被**外部压力**占掉了——压力来源有二：**已放下的星**（其邻格不能放星）、**1×n 区域**（占用某条线的星）。把压力算进来后区域的有效候选缩小，若全在 X 邻格内 → X 仍可打叉。

**例**：
```
     c0 c1 c2 c3
r0:  .  .  B  .
r1:  .  X  B  .
r2:  .  .  .  .
r3:  D  D  B  .
```
- B = `(0,2)(1,2)(3,2)`；X=`(1,1)` 挨着 `(0,2)(1,2)` 但够不着 `(3,2)` → 普通排除不触发。
- 压力：区域 D=`(3,0)(3,1)` 困在第 3 行 → 第 3 行星归 D → `(3,2)` 放不了。
- B 有效候选只剩 `(0,2)(1,2)`，都是 X 邻格 → X 打叉。

**关系/性质**：常可拆成"规则 6 + 规则 7"两小步，引擎多半走便宜路径（见 §1.4）；仅当它解锁简单序列达不到的格子时才作为独立难步计入。
**区间内因子**：① 同规则 7；② **纳入的压力源数量**（越多越难）。

### 规则 11 · 带鳍计数（Finned Counts）
**含义**：规则 8/9 的"差一格"版。k 个区域的候选**几乎**落在 k 条线内，只差一个候选（**鳍**）多伸到第 k+1 行。分两种情况：
- 鳍不是星 → 干净欠计数成立，其打叉生效；
- 鳍是星 → 鳍的邻格打叉。
**两种情况都被打叉的格 = （干净欠计数会打叉的格）∩（鳍的邻格）**，安全打叉。

**例（示意）**：
```
        ... c4 c5 c6 ...
行0:        A  A          A、B 候选主要在行 0/1
行1:     b  b  b          (1,4)(1,5)(1,6) 属别的区域
行2:           A          (2,5) 是鳍
```
- 鳍非星 → `(1,4)(1,5)(1,6)` 该打叉；鳍是星 → 其邻格 `(1,4)(1,5)(1,6)` 也打叉。
- 交集 → `(1,4)(1,5)(1,6)` 安全打叉。

**区间内因子**：① k 值 + 行/列（同规则 8/9）；② **鳍的复杂度**（鳍格越多、越散越难）。

### 规则 12 · 集合差分（Set Differentials）
**含义**：每行/列/区域都是"星数已知（=1）的集合"。把这些集合做**加减**，重叠抵消，推出某残余区块的**确切星数**，甚至直接定星。
核心等式：`星数(R) = 星数(若干行/列) − 星数(被减去的格) + 星数(被加上的格)`。

**例**（区域 R = 行0+行1，去掉 `(0,3)`、加上 `(2,0)`）：
```
        c0 c1 c2 c3
行0:     R  R  R  .      (0,3) 不属于 R
行1:     R  R  R  R
行2:     R  .  .  .      (2,0) 属于 R
```
- 行0+行1 共 2 星；R 是 1 个区域 = 1 星。
- `1 = 2 − x + y`（x=星?(0,3)，y=星?(2,0)）→ `x−y=1` → 唯一解 **x=1, y=0**。
- → `(0,3)` 必是星，`(2,0)` 必非星。（用到减法，普通鸽笼做不到。）

**区间内因子**：① 参与运算的集合数量（越多越难）；② 残余区块是否简单（紧凑连通更易）。

### 规则 13 · 鱼（Fish）
**含义**：完全不看区域，只在"行↔列"层计数。若 **n 个列**的星都只可能落在**同样的 n 个行**里 → 这 n 行的星被这 n 列包圆 → 这 n 行里**不属于这 n 列**的格子打叉。（行↔列对偶。）n=2 即 X-Wing，n=3 Swordfish……

**例**（X-Wing，4×4；第 0、2 列只剩行 0、1 可放）：
```
      c0 c1 c2 c3
r0:   O  ✗  O  ✗
r1:   O  ✗  O  ✗
r2:   ✗  .  ✗  .
r3:   ✗  .  ✗  .
```
- 第 0 列星在 `{行0,行1}`；第 2 列星也在 `{行0,行1}` → 2 列把行 0/1 的 2 颗星包圆。
- 行 0、行 1 里别的列 `(0,1)(0,3)(1,1)(1,3)` 打叉。

**区间内因子**：① 鱼的规模 n（越大越难）；② 行/列方向。

### 规则 14 · 带鳍鱼（Finned Fish）
**含义**：规则 13 的"差一格"版（鱼 + 鳍）。某列多出一个候选（鳍）伸到额外行，破坏了干净的鱼。分两种情况：
- 鳍不是星 → 退化为干净鱼，其打叉生效；
- 鳍是星 → 鳍的邻格打叉。
**交集 = （干净鱼会打叉的格）∩（鳍的邻格）** 安全打叉。

**例**（接 X-Wing，第 2 列多出鳍 `(2,2)`）：
```
      c0 c1 c2 c3
r0:   O  .  O  .
r1:   O  ✗  O  ✗     只有 (1,1)(1,3) 安全打叉
r2:   ✗  .  F  .     F=(2,2) 鳍
r3:   ✗  .  ✗  .
```
- 干净鱼会打叉 `(0,1)(0,3)(1,1)(1,3)`；鳍 `(2,2)` 邻格含 `(1,1)(1,3)`。
- 交集 → 仅 `(1,1)(1,3)` 安全打叉（`(0,1)(0,3)` 离鳍太远，不能打）。

**区间内因子**：① 鱼规模 n；② 行/列；③ 鳍的复杂度。

### 规则 15 · By a Thread（唯一性类）
**唯一性原理（15–17 共同基础）**：谜题只有一个解 → 任何"如果这样摆就会出现两个解"的局面都不可能发生 → 反过来排除会制造多解的摆法。

**致命矩形（多解陷阱）**：取两条**不相邻**的行 `r0,r2` 与两条**不相邻**的列 `c0,c2`，4 个角格中左列 `TL,BL` 属区域 P、右列 `TR,BR` 属区域 Q，且相关行/列/区域的星只能落在这 4 格：
```
        c0       c2
r0:    [TL=P]   [TR=Q]
r2:    [BL=P]   [BR=Q]
```
- 摆法①：星在 `TL,BR`；摆法②：星在 `TR,BL`——两种都满足行列区域各 1 星且不相邻 → **2 个解**，违反唯一性。

**By a Thread 用法**：既然致命矩形不可能真出现，当棋盘**只差一个"吊着"的格就要形成它**时，那个格被唯一性**强制确定**（否则掉进多解）——整个解"靠一根线吊着"。
**区间内因子**：① 涉及格子/区域数量；② 唯一性论证链条长度。
**提示**：极罕见，仅最难谜题偶现，实现优先级最低。

### 规则 16 · At Sea（唯一性类）
**含义**：把唯一性用于**多个"漂浮（欠定）"的区域**——它们的星用常规逻辑钉不死，像无锚的船漂在海上。若它们纠缠成一个**可轮换的结构**（星按两种轮转方式摆都合法）→ 自身就能产生多解；唯一性逼着它们只能锁定成其中一种对齐方式。
**与 15 的区别**：15 是紧凑的"一根线"局部；16 是松散的多区域"海域"（致命矩形的多区域推广 → 致命轮转环）。
**区间内因子**：① 涉及格子/区域数量；② 论证链条长度；③ 欠定海域规模（卷入区域越多越难）。
**提示**：极罕见，优先级最低。

### 规则 17 · By a Thread at Sea（唯一性类·最难）
**含义**：规则 15 与 16 的叠加——在一片本就要靠唯一性收敛的**漂浮海域**里，**再叠一层"靠一根线吊住"的唯一性论证**，两段论证连成最长推理链。
**为什么最难**：先识别多区域漂浮轮换结构（At Sea），再在其中找到唯一线头格（By a Thread），把两段唯一性论证串起来——认知负担最高，居阶梯顶端（再上即 Expert）。
**区间内因子**：综合 15、16 全部因子，论证链最长。
**提示**：比 15、16 还罕见，优先级最低。

## 4. 唯一性类与 Expert 的边界
- 规则 15–17 用"唯一解"假设，是**合法且最高档**的客观推理。
- 若一道题连规则 17 都用不上、纯逻辑仍无法推进（需要真正的盲猜/回溯）→ 归为 **Expert**（难度轴顶端之上）。
